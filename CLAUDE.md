# CLAUDE.md

## Project

Fast SDLC — an agentic framework for software development. The product being built is not application code: it is the agent and skill definitions that drive the SDLC pipeline itself (see `docs/validated-business-idea/latest.md`).

## Team

This project's pipeline does not follow the standard SDLC role set. Active roles:

- **product-strategist** — discovery and validation, as defined in the `sdlc` skill.
- **orchestrator** — acts as the sole workforce/implementor role on this project. There is no backend-developer, frontend-developer, devops, architect, or QA role: the orchestrator writes and maintains the agent and skill definitions directly, since those definitions ARE the deliverable.

See `docs/orchestrator-conventions.md` for how the orchestrator approaches implementation work here.
